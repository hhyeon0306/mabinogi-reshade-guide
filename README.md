# 마비노기 ReShade 가이드

제작 · **류트@벨밋**

컴퓨터에 익숙하지 않은 사용자를 위한 8단계 한국어 설치 가이드입니다. HTML, CSS, JavaScript와 Canvas2D로 만들었습니다.

- 실제 설치 화면 확대 및 누를 위치 표시
- Vulkan 설정에 맞춘 설치 방식 안내
- 단계 완료 표시를 브라우저 안에 저장
- 모바일 화면, 문제 해결, 제거 방법, 출처
- Vibrance 0.10의 간단한 설정 파일 제공
- 벨밋의 테스트 프리셋과 실제 게임 화면 전후 비교, UI 없는 촬영 안내

## 빠른 설치 순서

1. 게임의 **환경설정 → 실험실 → 렌더링 엔진(Vulkan)** 체크 여부를 기억하고 게임을 종료합니다.
2. [ReShade 공식 사이트](https://reshade.me/)에서 일반 버전 설치 파일을 받습니다. 이 안내는 full add-on support 버전을 사용하지 않습니다.
3. 설치 도구의 **Browse…**로 마비노기 폴더 안의 **Client.exe**를 선택합니다. 흔한 위치는 `C:\Nexon\Mabinogi\Client.exe`이지만 PC마다 다릅니다.
4. Vulkan 설정이 켜졌다면 **Vulkan**, 꺼졌다면 **DirectX 9**를 선택합니다. 별도 DXVK 환경도 Vulkan입니다.
5. **Standard effects**, **SweetFX by CeeJay.dk**를 선택하고 **Next → Finish**로 완료합니다.
6. 평소 방법으로 게임을 실행합니다. ReShade 안내를 확인하고 **Home**으로 설정창을 엽니다.
7. **Vibrance**를 켜고 값을 **0.10** 정도로 맞춥니다. 원래 색감으로 돌아가려면 효과의 체크를 끕니다.
8. 완전 제거는 게임 종료 후 설치 도구에서 같은 실행 파일·그래픽 방식을 선택하고 **Uninstall**로 진행합니다.

## 확인 범위

2026-09-25, ReShade 6.8.0 일반 버전을 사용했습니다. NVIDIA + Vulkan 환경에서 설치 성공, 게임 재실행 후 성공 안내, ReShade 설정창, Vibrance 활성화 및 0.100 값을 실제 확인했습니다. 자동 게임 입력이 전달되지 않아 일부 버튼·키 입력은 사용자가 수행했습니다. 색감 파일은 직접 작성하고 게임에서 불러왔습니다.

AMD에서도 지원되는 그래픽 방식으로 ReShade를 사용할 수 있지만 **AMD 실기 테스트는 수행하지 않았습니다.** 이 캡처는 모든 PC·게임 버전에서 동작을 보증하지 않습니다. 장시간 안정성이나 성능 차이 측정, DirectX 9 경로의 실제 설치 검증은 수행하지 않았습니다.

이 가이드는 비공식이며, 넥슨의 외부 프로그램 허용이나 제재 면제를 보장하지 않습니다. 공식 출처는 웹페이지의 ‘출처’에서 확인할 수 있습니다.

## 설정 파일

### 벨밋의 테스트 프리셋 (v1.0 검토본)

`Belmit-Test.ini`는 그림자를 밝게 들어 올리고 따뜻한 색감과 부드러운 대비를 더하는 프리셋입니다. 제작자가 게임에서 조절한 최신 수치를 반영했습니다. SweetFX의 LiftGammaGain, Tonemap, Vibrance, Curves, FXAA를 사용합니다. 배경만 흐리는 심도 효과는 포함하지 않습니다. [ReShade 공식 안내](https://reshade.me/)에 따르면 멀티플레이에서는 깊이 정보 접근이 자동으로 제한됩니다.

마비노기 설치 폴더에 넣은 뒤 Home으로 ReShade를 열고, 맨 위 프리셋 선택 부분에서 `Belmit-Test.ini`를 선택하세요. 글씨가 너무 부드러워지면 FXAA만 끄세요. 이전 프리셋을 선택하면 기존 색감으로 돌아갈 수 있습니다.

설치된 셰이더의 실제 변수 이름·범위를 대조하고, NVIDIA + Vulkan 게임에서 5개 효과의 활성화를 확인했습니다. ReShade의 전후 동시 저장 기능으로 촬영한 실제 사진을 제공합니다. 두 사진에는 같은 범위의 자르기만 적용했으며 별도 색 보정은 하지 않았습니다. 참고 이미지와 동일한 결과나 AMD PC 동작을 검증한 것은 아닙니다. 참고 이미지는 가이드에 재배포하지 않습니다.

### 기본 약한 색감

`Mabinogi-Soft.ini`는 Vibrance 0.10, RGB Balance 1/1/1만 설정합니다. 게임 폴더에 넣고 ReShade의 프리셋 선택 부분에서 선택하세요. SweetFX가 필요합니다. ReShade 실행 파일과 셰이더 파일은 포함하거나 재배포하지 않습니다.

## 진행 정보 저장

외부 분석 도구나 추적 코드는 사용하지 않습니다. 완료 표시는 방문자의 브라우저에만 저장됩니다.

## 열기

`index.html`을 브라우저로 열거나 정적 웹 호스팅에 전체 폴더를 올리면 됩니다. 별도 설치나 빌드가 필요 없습니다. 브라우저에서 로컬 저장을 제한하더라도 단계 이동은 사용할 수 있습니다.
