출처와 확인 범위

AMD에서도 ReShade를 사용할 수 있습니다. 그래픽카드 회사보다 게임이 사용하는 그래픽 방식과 드라이버 지원이 중요합니다.

  • ReShade 공식 사이트지원 그래픽 방식, 표준 설치 파일, 버전과 배포 안내
  • ReShade 6.8 릴리스 노트AMD 관련 수정 사항
  • 마비노기 공식 2026년 8월 6일 패치 안내환경설정 → 실험실 → 렌더링 엔진(Vulkan) 옵션 확인
  • ReShade 설치 도구 가이드실행 파일, 그래픽 방식과 효과 선택
  • DXVK 환경의 ReShadeDXVK 사용 시 Vulkan 선택
  • 설치 도구로 제거하기같은 게임 파일과 그래픽 방식으로 제거
  • 마비노기 운영정책이 가이드는 넥슨 공식 승인 또는 제재 면제를 보장하지 않습니다.

실제 설치 캡처는 NVIDIA PC의 Vulkan 환경에서 촬영했습니다. AMD PC 실기 테스트는 진행하지 않았습니다. 게임 업데이트와 보안 모듈에 따라 동작은 달라질 수 있습니다.

ReShade 실행 파일과 셰이더는 재배포하지 않습니다.
